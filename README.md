\# Industrial Product Intelligence



An AI-powered platform for collecting, structuring, validating, and tracing industrial product information.



\## Planned components



\- Backend API and AI processing pipeline

\- React dashboard

\- PostgreSQL database

\- Product specifications in flexible structured data

\- Source and evidence tracking



\## Repository structure



\- `backend/` — API, AI pipeline, and database code

\- `frontend/` — dashboard interface

\- `data/` — local raw, processed, and sample data

\- `docs/` — planning and technical documentation

\- `infra/` — deployment setup later

\- `scripts/` — maintenance and import tools

\- `tests/` — automated tests
